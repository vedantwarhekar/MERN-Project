# YouTube Backend Clone

## 🚀 Overview
This project is a backend clone of YouTube, designed to replicate core functionalities while introducing social media features. Users can subscribe to channels, create playlists, post tweets, and engage with content by liking comments and tweets. Built with modern backend technologies, this project demonstrates scalable and feature-rich API development.

---

## 🛠️ Features
- **User Authentication & Authorization**
  - Secure login and signup.
  - Role-based access control.
  - Cookie-based access token and refresh token generation.

- **Video Management**
  - Upload and store videos.
  - Metadata management (title, description, tags, etc.).
  - Adaptive video playback support.

- **Playlists**
  - Create and manage custom playlists.
  - Add or remove videos from playlists.

- **Channel Subscriptions**
  - Subscribe to channels and receive updates.
  - View subscriber count for each channel.

- **Tweet Functionality**
  - Post tweets and view those from other users.
  - Edit tweets (owners only).

- **Engagement Features**
  - Like and interact with video comments.
  - Toggle like/unlike on comments and tweets.
  - Edit comments (owners only).

- **Best Practices**
  - Implemented using modern programming practices for scalability, maintainability, and performance optimization.

---

## 🏗️ Tech Stack
- **Backend Framework**: Node.js, Express.js.
- **Database**: MongoDB.
- **ORM**: mongoose.
- **Authentication**: JWT(jeson web token).
- **Hasing**: bcrypt.
- **File uplodation**: multer.
- **Cloud-Based service**: cloudinary.
- **Formatter**: prettier.
